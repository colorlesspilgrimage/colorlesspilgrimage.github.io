Now

Late September in Saint Paul. The public project is gamelog, a Rust program for the games you actually play. This page is the first cut of the homepage — press T and it changes clothes.

  • Terminal first. A desktop window if you want one. Same library either way.

02

Work

One public project so far. More when they are worth the link.

Rust · MIT

gamelog

A terminal UI for logging the video games you play. Title, system, status, hours, a rating, cover art, and a note — kept as plain JSON in a single hidden directory.

t
Start a session. Stop it. The hours add themselves.
/
Search the library as you type. Sort is remembered.
--gui
A native window on the same files, when you want a mouse.

03

Defaults

  1. 01

    One directory.

    gamelog keeps the library, covers, keys, and settings in ~/.gamelog. If you can list it, you can trust it.

  2. 02

    Keys before chrome.

    The interesting actions are keystrokes, written down in a TOML file you can edit. The window is there for the days you do not want that.

  3. 03

    Leave a trail.

    Hours, a status, a note about why you stopped. A log is more honest than a backlog you will never open.
